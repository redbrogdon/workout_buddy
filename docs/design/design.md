# Design file index

Design for this project is being done in Stitch, Google's tool for agents to collaborate on UI designs. Here's what's there:

The following files have been exported from Stitch:

## Overall Theme
* [Cerulean Edge Design System](cerulean_edge/DESIGN.md) - The overarching design system document detailing the "Cerulean Edge" theme, including color palettes, typography, spacing, and component guidelines for the app's minimalist, high-performance aesthetic.
